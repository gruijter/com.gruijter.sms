En liten Homey-app för att skicka textmeddelanden via ett urval av över 90 SMS-leverantörer.

När du har konfigurerat SMS-leverantören du vill använda kan du skicka meddelanden via ett handlingsflödeskort.

ANVÄND DITT EGET SIM-KORT - installera httpSMS-appen på en gammal Android-telefon och använd krediten på ditt eget SIM-kort.

DELLMONT: Detta inkluderar mer än 60 voip-tjänster som Voipbuster, Freecall, Cheapvoip osv. Även dessa är betaltjänster, så du behöver ett konto och kredit för att använda dem.
