A small Homey app to send text messages via a choice of over 90 SMS providers.

After setting up the SMS-service provider you want to use, you have the possibility to send messages via an action flow card.

USE YOUR OWN SIM - install the httpSMS app on an old Android phone and use the credits of your own SIM card.
